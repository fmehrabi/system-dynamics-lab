# System Dynamics Lab

**System Dynamics Lab** is an interactive platform for exploring, simulating, and understanding dynamic systems through visual models and computational experimentation.

The platform provides a growing library of interactive system dynamics models, allowing users to explore stock–flow structures, modify model parameters, run simulations, and observe how changes influence system behavior over time.

### Purpose

Designed for educational and research-oriented exploration, System Dynamics Lab aims to make system dynamics more accessible through hands-on experimentation, visual analysis, and interactive learning.

### Key Features

- Interactive stock–flow diagrams
- Real-time simulation and visualization
- Adjustable model parameters
- Lookup functions and scenario analysis
- An expandable library of independent models

**Explore. Simulate. Understand.**
